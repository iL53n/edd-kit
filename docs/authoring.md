# Authoring EDD suites

The [packaged authoring reference](../src/edd_kit/assets/skills/edd-prepare/references/authoring.md)
is the single source for the contract, Python suite interface, target protocol, and evidence rules.
`edd init` installs it with the Prepare skill so it is available in adopting repositories and wheels.

For the high-level journey, read [the workflow](workflow.md). For the trust model, read
[security](../SECURITY.md).
